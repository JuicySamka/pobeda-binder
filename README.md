## ✨ Возможности

- 🗂 **Готовые фразы по этапам рейса:** регистрация, перед взлётом, полёт, посадка, старший бортпроводник
- 🔴 **Команды выделены красным:** `/:give`, `/:handto`, `/:privatemessage`, `/:n`, `/:sn` и другие
- 🏷 **Подстановка ника:** тег `{n}` заменяется ником игрока из поля «Ник»
- 🌐 **Два языка:** русский и английский, с учётом времени суток и обращения
- ✍️ **Свои фразы:** до 10 собственных кнопок с редактированием и удалением
- 🎨 **Светлая и тёмная темы** и плавный интерфейс
- 🔔 **Уведомление об обновлениях:** биндер сам сообщит о новой версии

## 📥 Установка

1. Скачай **[Pobeda_Binder_Setup.exe](https://github.com/Lshkka/pobeda-binder/releases/latest/download/Pobeda_Binder_Setup.exe)**
2. Запусти установщик и следуй подсказкам. AutoHotkey v2 установится автоматически, если его ещё нет
3. Открой биндер ярлыком на рабочем столе или в меню «Пуск»

> ⚠️ Windows может показать предупреждение SmartScreen, потому что установщик не подписан.
> Нажми **«Подробнее» → «Выполнить в любом случае»**.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `F1` | Показать / скрыть окно |
| `F2` | Выйти из биндера |
| ПКМ по своей фразе | Изменить или удалить |

## 🔄 Обновление

Когда выходит новая версия, биндер покажет уведомление. Либо скачай свежий установщик отсюда. Твои фразы и настройки сохранятся.
